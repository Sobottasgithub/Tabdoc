# Tablo Transfer Protocol 2
Any packet size, custom types, TCP or UDP - TTP2 moves data reliably and fast across your nodes with C++ and Nix reproducibility.

# What is TTP2?

The Tablo Transfer Protocol 2 (TTP2) transmits data packets of any size quickly and reliably. It is primarily designed for transferring
large data packets between clients, servers, and nodes within Tablo and TDFS. To accommodate a wide range of use cases, it provides
implementations for both TCP and UDP. Should the existing packet types prove insufficient for your specific requirements, TTP2 can be
extended with custom packet types with minimal effort. It is written in C++ and based on Nix.
