# Tablo UDP Discovery

Discover your peers, clients and servers fast and reliably with Tablo UDP Discovery. Written in C++, powered by Nix, used by Tablo.

# What is Tablo UDP Discovery

If you want to connect multiple peers over a network or allow clients to find servers automatically without
manually configuring IP addresses and ports, Tablo UDP Discovery is the ideal library for you.
TUD's main goal is to work reliably with minimal setup without cutting corners at viable functions.
