# Test Tablog

If you want to test how Tablog functions and appears, you only need to run a single command:

```Bash
nix run github:Sobottasgithub/tablog#test
```

Tablog displays several different configured log outputs.

## Source

You can find the source code to the test implementation here: [Tablog/test](https://github.com/Sobottasgithub/Tablog/tree/main/test)
